# mta-sts-redline

MTA-STS policy for redlinetechniques.com, served by GitHub Pages at https://mta-sts.redlinetechniques.com/.well-known/mta-sts.txt

Mail for redlinetechniques.com is handled by iCloud (mx01/mx02.mail.icloud.com). Mode starts at `testing`; switch to `enforce` after clean TLS-RPT reports, then bump the id in the `_mta-sts` DNS TXT record.
